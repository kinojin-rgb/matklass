# MatKlass — бесплатная версия с автоматической и ручной проверкой

## Что реализовано в этой сборке
- Ученик входит без регистрации: вводит имя и фамилию.
- Преподаватель входит по постоянному пятизначному коду. Код хранится в секрете Supabase Edge Function, а не в HTML/JavaScript.
- Преподаватель вручную пишет каждое задание, выбирает тип ответа и баллы.
- Три типа проверки:
  - `Выбор варианта` — автоматическая проверка совпадения с правильным вариантом.
  - `Числовой ответ` — автоматическая проверка числа с заданной допустимой погрешностью.
  - `Развёрнутое решение` — ответ ученика сохраняется, преподаватель проверяет его в разделе «Проверка ответов» и выставляет баллы.
- Математическая клавиатура.
- Необязательные сохранённые шаблоны с переменной `{n}`. Преподаватель задаёт диапазон, условие и формулу. Кнопка создаёт конкретное задание с выбранным случайным целым n и вычисляет правильный ответ. После этого преподаватель может отредактировать условие/ответ как обычное задание.
- Таймер, серверное сохранение ответов, панель статусов.
- Если сервер не получает сигнал активности более 5 секунд, попытка аннулируется.
- Бесплатная публикация фронтенда через GitHub Pages и сервер через Supabase Free.

## Честные ограничения
Это готовая учебная версия для пробного запуска, но не сертифицированная экзаменационная система. Шаблоны пока поддерживают одну целочисленную переменную `{n}` и арифметические формулы с `+ - * / ^` и скобками; это не универсальная система символьной математики. Автопроверка чисел не проверяет эквивалентность алгебраических выражений (например, `1/2` и `0.5`): для таких ответов используй ручную проверку. Ручная проверка поддерживает выставление баллов и комментария. Пока нет редактирования опубликованной работы, восстановления попытки после сетевого сбоя, загрузки рисунков к заданиям, сложных формул и полноценной истории событий выхода. Проверяй сначала на вымышленных данных.

## Бесплатные сервисы и лимиты
- GitHub Pages доступен бесплатно для публичных репозиториев на GitHub Free.
- Supabase Free включает квоты, в том числе 500 000 вызовов Edge Functions в месяц, 500 MB базы, 5 GB исходящего трафика и 200 пиковых Realtime-подключений. Проекты Free могут приостанавливаться после недели бездействия. Лимиты могут меняться; проверяй официальные страницы.
- При 30 одновременно работающих учениках heartbeat раз в 2 секунды — примерно 54 000 вызовов функции в час. Контрольная на 30 минут — около 27 000 вызовов, не считая сохранения ответов и запросов панели. При нескольких контрольных в месяц квота может закончиться. Это расчёт нагрузки, а не гарантия производительности.
- Не переходи на платный тариф и не добавляй платёжные данные, если хочешь строго бесплатный режим. Проверяй Usage в Supabase.

## Часть A. Создай Supabase
1. Открой https://supabase.com/dashboard и создай проект на Free.
2. Не выбирай платный тариф и не подключай платные add-ons.
3. Задай пароль базы данных и сохрани его в безопасном месте.
4. Дождись создания проекта.
5. Открой SQL Editor -> New query.
6. Открой `supabase/schema.sql` из этого архива, скопируй весь текст, вставь в редактор и нажми Run.
7. Открой Project Settings -> API. Скопируй Project URL и publishable key (или anon public key).

## Часть B. Заполни config.js
Открой `config.js` и замени только значения:
- `SUPABASE_URL` — Project URL;
- `SUPABASE_ANON_KEY` — publishable/anon public key.

Пример:
```js
window.MATKLASS_CONFIG = {
  SUPABASE_URL: "https://abcxyz.supabase.co",
  SUPABASE_ANON_KEY: "твой-публичный-ключ"
};
```
В этот файл НЕЛЬЗЯ вставлять `service_role`, `secret key`, пароль базы или пятизначный код учителя. Публичный ключ специально предназначен для браузера; права на таблицы закрыты RLS, запросы идут через Edge Function.

## Часть C. Установи Supabase CLI и разверни сервер
На Windows:
1. Установи Node.js LTS: https://nodejs.org/
2. Установи Git: https://git-scm.com/download/win
3. Распакуй архив проекта в папку, например `C:\\MatKlass`.
4. Открой PowerShell именно в папке `C:\\MatKlass`.
5. Проверь Node: `node -v`
6. Проверь CLI: `npx supabase --version` (если спросит установить пакет, подтверди).
7. Войди в Supabase: `npx supabase login` — браузер попросит подтвердить вход.
8. Найди Project Ref в адресе панели/URL проекта. Он выглядит как короткий идентификатор в `https://PROJECT_REF.supabase.co`.
9. Привяжи проект:
   `npx supabase link --project-ref PROJECT_REF`
10. Придумай постоянный пятизначный код преподавателя. Не используй 00000, 11111 или очевидные даты. Установи секрет:
   `npx supabase secrets set TEACHER_CODE=58317`
   Замени пример на собственный код.
11. Разверни серверную функцию:
   `npx supabase functions deploy matklass`
12. В Supabase Dashboard -> Edge Functions проверь, что `matklass` появилась.

Не публикуй код преподавателя и не вставляй его в файлы сайта. Для смены кода повтори команду `secrets set` с новым значением и снова deploy функцию.

## Часть D. Опубликуй сайт через GitHub Pages
1. Создай на GitHub новый **Public** репозиторий с именем `matklass`.
2. Распакуй архив. Убедись, что в корне рядом лежат `index.html`, `app.js`, `style.css`, `config.js`, папка `supabase` и скрытая папка `.github`.
3. В PowerShell в корне проекта выполни:
   ```powershell
   git init -b main
   git add .
   git commit -m "Initial MatKlass version"
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/matklass.git
   git push -u origin main
   ```
   Если Git запросит авторизацию, войди в браузере.
4. На GitHub открой репозиторий -> Settings -> Pages.
5. В Build and deployment выбери Source: **GitHub Actions**.
6. Открой вкладку Actions. Дождись зелёного workflow `Publish MatKlass`.
7. Адрес сайта будет `https://ТВОЙ_ЛОГИН.github.io/matklass/`.

Важно: репозиторий публичный, как и файлы сайта. Не загружай в него реальные ответы, персональные данные учеников, коды доступа или секретные ключи. Публичный ключ Supabase в config.js допустим, потому что он рассчитан на браузер и таблицы защищены RLS.

## Часть E. Проверка перед использованием
1. Открой опубликованный сайт.
2. Войди как преподаватель с пятизначным кодом.
3. Создай тестовую работу и вручную добавь:
   - один вопрос с вариантами;
   - один числовой вопрос с правильным ответом и погрешностью;
   - один вопрос с развёрнутым решением.
4. Для проверки шаблона заполни условие с `{n}`, например `Вычисли 4*{n}+3`, формулу `4*n+3`, диапазон `1..10`, сохрани шаблон и создай задание по нему.
5. Опубликуй работу.
6. Открой сайт в другом браузере/на телефоне и войди под тестовыми именем и фамилией.
7. Проверь отправку ответов, завершение, автоматическую проверку и появление развёрнутого ответа в «Проверка ответов».
8. Выставь ручные баллы и проверь итог в мониторинге.
9. Отдельно проверь правило пяти секунд на тестовой попытке. Не используй настоящую контрольную для первого теста.
10. В Supabase Dashboard -> Usage следи за расходом квот.
